# 📖 Посібник передавача ESP32 + Ra-01H (README)

## 🛠️ Апаратне підключення (Hardware Setup)

* **Плата (Board):** ESP32 DevKit v1
* **Модуль:** Ra-01H (SX1276)
* **Зіставлення пінів (Маркування на платі → Код GPIO):**
* `D18` (SCK) → GPIO 18
* `D19` (MISO) → GPIO 19
* `D23` (MOSI) → GPIO 23
* `D27` (NSS / CS) → GPIO 27
* `D14` (RST) → GPIO 14
* `D26` (DIO0) → GPIO 26


* **Швидкість передачі (Baud Rate):** 115200 (Serial Monitor)
* **Закінчення рядка (Line Ending):** Newline або Both NL & CR

---

## ⚙️ Параметри конфігурації (команда `config`)

**Синаксис:** `config RUN POINT PRESET MODE COUNT INTERVAL_MS POWER_DBM`

Приклад: `config 1001 1 1 0 100 200000 10`

| Параметр | Тип | Опис |
| --- | --- | --- |
| **RUN** | `uint32_t` | Унікальний ID експерименту (напр., `1001`). ESP32 запам'ятовує останній ID і **відмовиться стартувати**, якщо ви спробуєте використати його повторно. |
| **POINT** | `uint16_t` | ID точки вимірювання (напр., `1`, `2`, `3`). Корисно при переміщенні передавача в різні локації. |
| **PRESET** | `1` – `5` | Пресет модему LoRa (див. таблицю нижче). |
| **MODE** | `0` або `1` | `0` = Одностороння (тільки TX, без ACK).<br>

<br>`1` = Двостороння (TX чекає на ACK від приймача для розрахунку PDR). |
| **COUNT** | `1` – `10000` | Загальна кількість пакетів для передачі в цьому сеансі. |
| **INTERVAL_MS** | `uint32_t` | Час очікування між передачами в мілісекундах. Має перевищувати мінімальний інтервал для дотримання 1% робочого циклу (duty cycle). |
| **POWER_DBM** | `2` – `17` | Потужність передачі в дБм (PA_BOOST). |

### 📊 Таблиця пресетів (команда `table`)

| Пресет | Фактор розширення (SF) | Ширина смуги (BW) | Швидкість кодування (CR) | Мін. інтервал (мс) |
| --- | --- | --- | --- | --- |
| 1 | 7 | 125 кГц | 4/5 | ~16,000 |
| 2 | 9 | 125 кГц | 4/5 | ~41,000 |
| 3 | 12 | 125 кГц | 4/5 | ~148,000 |
| 4 | 7 | 250 кГц | 4/5 | ~8,500 |
| 5 | 7 | 125 кГц | 4/8 | ~28,000 |

## 💻 Послідовні команди (Serial Commands)

| Команда | Опис |
| --- | --- |
| `help` або `?` | Виводить список команд у Serial Monitor. |
| `status` | Виводить поточний стан радіомодуля, статус активності, помилок та конфігурацію. |
| `table` | Виводить 5 доступних пресетів LoRa та їх мінімальні інтервали. |
| `config ...` | Оновлює та зберігає конфігурацію експерименту в енергонезалежну пам'ять NVS. |
| `start` | Запускає експеримент. Чекає 5 секунд для ініціалізації приймача, після чого починає передачу. |
| `stop` | Миттєво перериває поточний експеримент. |
| `reset` | Очищає змінні `seq`, `ackCount` та `fault` вручну без видалення CSV-файлу. |
| `dump` | Виводить весь файл `/measurements.csv` у Serial Monitor. |
| `erase YES` | Видаляє файл `/measurements.csv` (створює новий порожній CSV для наступного запуску). |
| `format YES` | Форматує розділ пам'яті LittleFS (використовуйте лише при першому завантаженні або збої файлової системи). |

## 📈 Формат виводу CSV

Дані зберігаються у `/measurements.csv`. Їх можна легко експортувати за допомогою команди `dump` або нашого Python-скрипта.

**Стовпчики:**

1. `schema`: Завжди `1`
2. `node`: Завжди `A` (Передавач)
3. `boot_id`: Випадковий ID, згенерований під час завантаження ESP32.
4. `event`: Подія, що сталася.
5. `run_id`: Ваш налаштований ID експерименту.
6. `point_id`: ID точки вимірювання.
7. `preset`: Пресет модему.
8. `mode`: Режим роботи.
9. `seq`: Поточний порядковий номер пакета.
10. `t_ms`: Мілісекунди з моменту завантаження ESP32.
11. `freq_hz`: Частота (868100000).
12. `sf`: Фактор розширення (Spreading Factor).
13. `bw_hz`: Ширина смуги пропускання.
14. `cr_den`: Знаменник швидкості кодування.
15. `tx_power_dbm`: Потужність передачі.
16. `packet_bytes`: Завжди `32`.
17. `planned_count`: Запланована кількість пакетів.
18. `interval_ms`: Налаштований інтервал.
19. `toa_ms`: Час в ефірі (Time on Air, розрахований).
20. `rssi_dbm`: Рівень прийнятого сигналу (тільки для `ACK_RX`).
21. `snr_db`: Відношення сигнал/шум (тільки для `ACK_RX`).
22. `pdr_pct`: Сукупний коефіцієнт доставки пакетів (0.00 – 100.00).
23. `ack_count`: Загальна кількість успішно отриманих ACK.

**Типи подій:** `START`, `TX_ATTEMPT`, `TX_DONE`, `ACK_RX`, `ACK_TIMEOUT`, `TX_UNCERTAIN`, `TX_FAIL`, `END`, `STOP`.

## 💾 Флеш-пам'ять та обмеження сховища

* **Місткість:** Близько 30–40 експериментів (8 000–10 000 рядків), перш ніж розділ LittleFS об'ємом 1.5 МБ заповниться.
* *Порада:* Регулярно використовуйте `dump` для збереження даних на ПК та `erase YES` для очищення пам'яті.

---

## 🔄 Рекомендований робочий процес для нового експерименту

1. **Змінити конфігурацію:** `config 1002 1 1 1 100 200000 14`
2. **Очистити старі дані (рекомендується):** `erase YES`
3. **Запустити експеримент:** `start`
4. **Експортувати дані:** `dump` (або скористайтесь `serial_monitor.py` для автоматичного збереження).
